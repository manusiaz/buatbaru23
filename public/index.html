Pertanyaan

Apakah foto saya disimpan di server?

Tidak. File asli tetap di Google Drive kamu. Kami hanya membuat pratinjau kecil ber-watermark dan menghapusnya otomatis setelah sesi selesai.

Pelanggan perlu daftar akun?

Tidak. Cukup link dan PIN 4–6 digit. PIN terkunci 15 menit setelah 5 kali salah.

Kalau sinyal pelanggan jelek dan waktunya habis?

Setiap ketukan langsung tersimpan di server, jadi pilihan yang sudah dibuat tidak hilang. Pelanggan bisa menekan "Minta tambah waktu", dan admin menambah 5, 10, atau 15 menit dengan satu ketukan.

Kalau pelanggan mau ganti pilihan setelah dikirim?

Pilihan terkunci setelah dikirim. Admin bisa membukanya ulang dari dasbor; semua tercatat di log aktivitas.

Nama file kembar dari dua kamera?

Ditandai saat sinkron, nama subfolder ikut tampil, dan path lengkap ikut di ekspor CSV.
