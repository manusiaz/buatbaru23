Kebijakan privasi

Berlaku sejak November 2026. Disusun mengacu pada UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi.

Data yang kami proses

Untuk pelanggan studio: nama, nomor WhatsApp, foto pilihan, catatan, dan waktu akses galeri. Untuk staf studio: nama, email, dan peran. Kami tidak meminta data lain.

Foto

File asli tetap disimpan di Google Drive milik studio. Kami hanya menyimpan pratinjau kecil ber-watermark untuk ditampilkan di galeri, dan menghapusnya otomatis setelah sesi selesai sesuai masa retensi yang diatur studio (default 30 hari). Link dan ID file Google Drive tidak pernah dikirim ke browser pelanggan.

Akses Google Drive

Bila studio memilih folder lewat Google, aplikasi memakai izin drive.file hanya untuk folder yang dipilih, lalu membagikan folder itu ke email layanan kami sebagai Pelihat. Token Google studio tidak disimpan.

Keamanan

Galeri dilindungi link acak dan PIN. PIN dan kata sandi disimpan dalam bentuk hash. Semua aktivitas sesi dicatat di log untuk menyelesaikan sengketa waktu; log disimpan 12 bulan.

Hak kamu

Kamu bisa meminta akses, perbaikan, atau penghapusan data lewat studio yang memotretmu. Studio dapat menghapus galeri beserta data pelanggan dari dasbor; permintaan diselesaikan paling lambat 3 hari kerja.
